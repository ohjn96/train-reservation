라이선스 안내

앱을 쓰는 사람과 발급하는 사람 모두를 위한 문서.

앱을 쓰려면

  1. 요청 — 앱 실행 → [라이선스 요청하기]. 머신 ID 가 채워진 폼이 열림
  2. 제출 — 이름과 용도 기입
  3. 대기 — 승인되면 앱이 알아서 활성화. 화면 켜둔 채로, 최대 5분
  • 발급받은 PC 에서만 유효. 다른 PC 로 이전 불가
  • OS 재설치 시 머신 ID 변경 → 재발급 필요
  • 활성화 후에는 인터넷 연결만 있으면 됨

발급하려면

요청이 오면 알림 메일 도착. 메일에 답장하거나 이슈에 댓글.

/approve         30일 발급
/approve 90      90일 발급
/autorenew 30    만료 3일 전마다 30일씩 자동 연장
/autorenew off   자동 갱신 끄기
/revoke          이 PC 차단
/deny            거절
  • 서명·발급·커밋·이슈 닫기는 GitHub Actions 가 처리
  • 저장소 쓰기 권한자의 요청은 댓글 없이 즉시 발급

검사 켜고 끄기

정책 파일은 서명되어야 앱이 받아들임. 브라우저에서는 불가 — 개인키가 필요.

python scripts/license_admin.py policy --mode licensed   검사 켜기
python scripts/license_admin.py policy --mode open       끄기
python scripts/license_admin.py policy --mode blocked    전면 차단
git add license-policy.json && git commit -m "..." && git push
  • 앱은 6시간마다, 그리고 로그인할 때마다 확인
  • CDN 캐시로 반영까지 최대 5분

자주 나오는 상황

화면에 나오는 말원인조치
다른 PC 앞으로 발급된 것입니다 PC 교체 · OS 재설치새 머신 ID 로 재요청
라이선스가 만료되었습니다 기간 종료연장 요청
정책을 확인하지 못했습니다 인터넷 차단연결 확인 후 재실행
시스템 시계가 과거로… PC 시간 오류시간 동기화
승인했는데 활성화 안 됨 CDN 캐시최대 5분 대기
